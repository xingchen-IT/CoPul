## 复跑方式

```
# 配对矩阵（约 10 分钟）
python tools/m15/run_pairwise.py

# DWM 侧（约 5 分钟，本机环境下结论不可用）
python tools/m15/dwm_side.py 25
python tools/m15/dwm_levels.py 22
```

折叠对照改 `%APPDATA%\CoPul\config.json` 的 `CollapsedBlocks`（`["fps"]` / `["trend","temp"]` / `[]`），
**跑完记得还原**。`tools/m15` 目录下的 `cfg-*.txt` 是当时用过的几份配置快照。
