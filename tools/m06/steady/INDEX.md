`M06Bench.exe <out> <intervalMs> --steady-only [--repeat N]`，提权，20 逻辑核，60 秒窗口（±0.026%）。
报告结论见 `docs/M0.6-Provider落地与T0补测报告.md` 第 9.2 / 9.3 / 9.4 节。

## 代码代次

| 代次 | 特征 | 文件后缀 |

| 旧 | 无预热，`Start()` 后 1.3 秒即开始计时（tiered JIT 未收敛） | `-100ms` / `-500ms` / `-2000ms` / `-r2` / `-r3` |

## 读数怎么用

1. **取最坏值**，不取第一次，也不取平均。1s 档三次差 22%，2s 档六次差近 3 倍，0.5s 档（R17 后）三轮差 3 倍。
2. **不同代次别混着算中位数**。
3. 0.5s 档在旧代次两次完全一致（0.651 / 0.651）、R17 后却离散到 0.208–0.625 —— **"重复性完美"这个结论不成立**，它只是两个样本的巧合。
4. 2s 档的离散原以为是 R17（0.3% 固定开销），**9.4 已证伪该假设**（1s 档改动前后中位都是 0.417%）。来源仍未归因。
5. R17 后的测量一律用 `--repeat 3` 在**同一进程**内跑：分开弹多次 UAC 会被系统丢弃，且第 2 轮起不必再预热。
