## 读数怎么用

1. **取最坏值**，不取第一次，也不取平均。1s 档三次差 22%，2s 档六次差近 3 倍。
2. **不同代次别混着算中位数**。
3. 0.5s 档两次完全一致（0.651 / 0.651），是唯一重复性完美的挡位，可作交叉验证基准。
4. 2s 档的离散来自 R17（约 0.3% 的挡位无关固定开销），不是窗口精度问题。
