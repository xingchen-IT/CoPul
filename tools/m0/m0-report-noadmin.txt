---------------- 8. 结论 ----------------
  判定口径：不仅看传感器是否存在，还看是否读出了非空值。存在但无值 = 驱动未生效。

  CPU 温度   : 存在  31 个 / 有值   0 个   => 传感器在但全为 null，驱动未生效
  CPU 功耗   : 存在   4 个 / 有值   4 个   => 可用
  GPU 温度   : 存在   3 个 / 有值   3 个   => 可用
  GPU 功耗   : 存在   1 个 / 有值   1 个   => 可用
  存储枚举   : ** 完全为空 **
  硬盘温度   : 存在   0 个 / 有值   0 个   => 传感器缺失

  风扇转速   : 存在   0 个 / 有值   0 个   => 传感器缺失

  提示：本次为非管理员运行。上述 null / 0 值不能代表硬件不支持，必须提权重跑后再下结论。
