# M4.39 图标重绘：推力喷管

> **⚠ 已被 M4.40 取代**：用户指出想要的是第一轮候选里的「3 号 字母 C · 脉冲环」
> （沟通歧义——"选 3" 指的是三个候选里的第 3 个概念，不是"给第 13 个加细节"）。
> 现行为字母 C，见 `docs/M4.40-图标换成字母C.md`。本文保留当时的推理与踩坑记录：
> 光晕不能同心圆叠加、托盘反相版会读成高脚杯、16px 必须另给一套几何 —— 这三条仍然有效。

> 需求：「现在的图标还是不好看，再帮我重绘一下要大胆想象，不要只拘泥于折线图等」
> 选定：「选 3 增加细节」——在第四轮四个方向里选 13 号推力喷管，并要求加细节。

## 1. 旧图标的问题

上一版（F 趋势切面，`7d40ee6`）是一张"折线从左下冲向右上"。它对，但不独特：

- **谁都能用**。股票、健康、监控、网速、任何有"趋势"的工具换个颜色就是同一枚图标。
- **16px 会死**。折线宽度 0.05×16 ≈ 0.8px，缩到托盘尺寸后是一条发虚的噪点曲线。
- 上一版自己写下的理由是"个性来自动势"，但**动势只在大尺寸成立**，
  图标最小、最需要辨识度的那个尺寸恰恰没有。

## 2. 方向是怎么选出来的

一共出了四轮 16 个概念（`tools/icon-concepts.py`，可重跑）：

| 轮 | 概念 | 结论 |
|---|---|---|
| 1 | 切面核心 / 光圈虹膜 / 字母C / 锁定准星 | 太保守；准星 16px 会糊 |
| 2 | 机甲面罩 / 能量罐 / 切口方块 / 叠层斜条 | 面罩像磁带、切口方块像文件夹角 |
| 3 | 仪表指针 / 芯片 / 压力罐 / 棱晶 | 仪表可用但仍是"界面控件"语汇 |
| 4 | **推力喷管** / 三角翼 / 雷达 / 机械镜头 | **选定 13**，用户要求加细节 |

选它不是因为好看，而是**它换掉的是语汇本身**：前三轮都在画"数据长什么样"，
它画的是"这台机器在干什么"。而且竖构图在系统托盘里天然占位 ——
旁边一片横条和圆环，一个上重下轻的竖直亮条最容易被一眼捞出来。

**竖构图还有工程意义**：16px 只有 256 个像素，竖条的亮区横向占满 1/3 画幅，
缩到最小还剩 5~6 个像素宽；细线类图形在这个尺度上是不可救的。

## 3. 细节（"增加细节"具体加在哪）

| # | 零件 | 作用 |
|---|---|---|
| 1 | 安装法兰 | 顶部浅钢横板，喷管有"装在某处"的确定感，不是飘着的 |
| 2 | 燃烧室 → 喉部 → 钟形扩张 | **型线三段**。第一版是直边梯形，读出来像灯罩；有了"腰"才像发动机 |
| 3 | 冷却管 6 根 | 沿型线母线走，只在大尺寸画（≤32 会变成噪点） |
| 4 | 出口环 | 给喷口一点金属厚度，否则那一圈只剩一根线 |
| 5 | 琥珀唇环 | 全图唯一暖色，也是"高温"的信号 |
| 6 | 尾焰三层 | 青边 → 淡青 → 白芯，中段外凸（直边三角形会读成交通锥） |
| 7 | 激波钻石 3 颗 | 超音速尾焰里周期性出现的亮结，真发动机才有 |

### 两个配色上的坑

**① 激波钻石不能用"白芯 + 白钻"**。第一版芯是 `#EAF4F8`、钻也是白的，结果一颗都看不见。
必须让芯退到淡青 `#6ED8E8`、钻才是纯白 —— 对比是靠"芯更暗"换来的。

**② 托盘反相版不能用白尾焰**。亮青底 + 白三角 = 一整块高光，读出来像**高脚杯**。
改法：整个发动机（喷管 + 尾焰 + 唇环）统一做成深色剪影，才像"同一台机器"。

## 4. 小尺寸单独一套几何

16px 用大图那套（喷管 30%、尾焰 42%）时，喷管会被压成一条暗线，
最后只剩一团亮三角，"发动机"这个信息整个丢掉。所以 `size <= 24` 走另一套：

| | 大尺寸 | 小尺寸 |
|---|---|---|
| 喷管高度 | 34% | 40% |
| 出口宽度 | 43% | 60% |
| 钢色 | `#3A4A5E` | 提亮到 `#6A8098` |
| 冷却管 / 钻石 / 光晕 | 有 | **全部去掉** |

去掉光晕是最后一步：16px 下一层柔光会把"喷管 / 唇环 / 尾焰"三段糊成一个亮斑，
轮廓比发光感值钱。
