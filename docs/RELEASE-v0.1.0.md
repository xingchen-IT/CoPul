# CoPul 芯脉 v0.1.0

> 把 CPU、GPU、内存、硬盘、网络、帧率贴在 Windows 任务栏上。三种视图、点击穿透、全屏游戏自动让路。

首个公开版本。常驻托盘，不弹大窗口打扰：数字出现在你本来就在看的地方。

| 视图 | 形态 | 适合 |
| --- | --- | --- |
| 任务栏条 | 贴在任务栏空白区的一条，默认点击穿透 | 一直看得见，又不占地方 |
| 悬浮窗 | 可拖动、可吸附边缘的窄条，可横排可竖排 | 全屏游戏 / 全屏视频时看 |
| 大窗口 | 卡片式面板：占用、趋势、温度、内存、硬盘、网络、进程 | 想看清楚的时候 |

三个视图共用同一份采集与配置，可以同时开着，也可以随时全部收起（`Ctrl + Alt + C`）。

## 首次运行会看到什么

1. **「Windows 已保护你的电脑」** —— 本程序**没有代码签名证书**（个人开发者买不起 EV 证书），SmartScreen 会拦一下。
   点「更多信息」→「仍要运行」即可。这不是病毒提示，只是"没见过这个发布者"。
2. **许可协议** —— 首次启动弹一次，条款可滚动，勾选同意才能继续。不同意则退出，不采集任何数据。
   同意结果（版本 + 时间）记在配置里，之后不再询问。
3. 手动启动会直接打开大窗口；开机自启则以任务栏条出现。点 `×` 只是隐藏，真退出用托盘菜单 →「退出」。
4. 托盘图标可能被折进任务栏的 `^` 里，拖出来更顺手。

## 想要看到完整数据

**必须两件事同时满足**，缺一不可：

| 项目 | 要求 | 缺了会怎样 |
| --- | --- | --- |
| 权限 | **以管理员身份运行 CoPul** | CPU 温度、整机功耗、CPU 频率、硬盘温度、FPS 显示 `—` |
| 驱动 | 安装 [PawnIO](https://pawnio.eu/) | 温度与功耗仍然 `—`（`rdmsr` 是特权指令，必须有内核态驱动） |

PawnIO 是开源、带签名的通用驱动（LibreHardwareMonitor 生态同款），**不随本程序分发**，需自行安装一次：
官网 <https://pawnio.eu/>，或直链 <https://github.com/namazso/PawnIO.Setup/releases/latest/download/PawnIO_setup.exe>。
安装时保持默认 **Official edition**，装完重启 CoPul 即可，多数情况不用重启系统。

设置页 →「传感器诊断」会逐项列出每个采集器的实际状态和补救建议。

## 系统要求

- Windows 10 1809 及以上 / Windows 11，**x64**
- 自包含发布，**不需要预装 .NET 运行时**
- **GPU 指标只支持 NVIDIA**（走 NVML）。AMD / Intel 显卡只显示型号，占用、温度、显存一律 `—`
- **硬盘温度只支持 NVMe**。SATA 盘读不到（v1 限制）
- 开发与验证只在 Windows 11 + Intel 13 代 + RTX 4060 上做过，其他硬件欢迎在 Issues 反馈

> 上面三项属于「本机本来就没有这块硬件」，不算配置错误 —— 状态灯不会因为它们变橙，只在状态栏写一句「未启用 xxx」。
> 真正点亮橙灯（降级运行）的是「硬件在、但读不到」：没提权、驱动被拦、PresentMon 起不来。

## 资源占用

实测：i7-13650HX（14 核 20 线程）+ RTX 4060 Laptop + Windows 11，普通权限，采集间隔取默认 500 ms，
预热 10 秒后取 60 秒窗口，每种形态重复 2～4 次取中位数。

| 形态 | 单核占用 |
| --- | --- |
| 只采集，不显示任何窗口 | 1.3% |
| 悬浮窗 | 2.2% |
| 任务栏条 | 2.3% |
| 大窗口 | 2.6% |

「单核占用」= 占满一个逻辑核的百分比；换算整机是 0.1% 量级。成本主要花在**把新数据画进界面**那一拍，
静止的窗口不额外吃 CPU。采集间隔放宽到 1000 ms，各项再降 0.3～0.7 个百分点。

管理员运行时还会多采集温度、功耗、FPS，开销会略高。

## 安装与卸载

**安装**：双击 `CoPul-0.1.0-setup-x64.exe` → 选路径（默认 `%LOCALAPPDATA%\Programs\CoPul`）→ 完成。
可用 `/DIR=` 指定路径，例如：

```
CoPul-0.1.0-setup-x64.exe /VERYSILENT /DIR="D:\Apps\CoPul"
```

**卸载**：设置 →「应用」→ CoPul → 卸载；或开始菜单 → CoPul → 卸载。
卸载时会问要不要一并删除配置（`%APPDATA%\CoPul`）与日志（`%LOCALAPPDATA%\CoPul`）：
选「否」（默认）保留设置，重装后还在；选「是」清干净。静默卸载默认**保留**，需 `COPUL_PURGE=1` 才删。

## 已知限制

- **独占全屏游戏**里任何覆盖层都上不了屏（DWM 独立翻转），这是系统行为。CoPul 的做法是全屏时自动让路，不是"修好了"。
- **任务栏条**依赖 `Shell_TrayWnd` 结构，第三方任务栏工具（StartAllBack、ExplorerPatcher 等）未适配，可能错位；
  目前只在**底部任务栏 + 系统默认尺寸**下验证过，任务栏在顶部/左侧或改了高度时位置可能不对。
- **反作弊**：覆盖层在技术上可能被个别反作弊判为异常，进竞技类网游前建议先收起浮窗。
- 副屏任务栏未适配（单屏开发，验不了）。
