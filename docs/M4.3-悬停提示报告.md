# M4.3 任务栏条悬停提示 阶段报告

- 日期：2026-10-30
- 范围：需求 **7.6**（鼠标悬停显示 tooltip：各指标完整名称，尤其硬盘温度对应哪块盘）
- 未含：副屏任务栏、G-03/04/05/08/09

---

## 1. 死结：穿透之后没有 hover

7.6 同时要求两件互相拆台的事：

| 要求 | 后果 |
| --- | --- |
| 左键**默认穿透**（Q-12 方案 2） | `WM_NCHITTEST` 返回 `HTTRANSPARENT`，鼠标消息根本不投给条 |
| 悬停显示 tooltip | 收不到 `WM_MOUSEMOVE`，WPF 的 `MouseEnter` / `ToolTip` 永远不会触发 |

只按字面实现其中一条，另一条必然是假的。三条出路：

| 方案 | 评价 |
| --- | --- |
| 只在"可点击"时给 tooltip | 零成本，但用户得先去托盘关掉穿透才看得到 —— 功能名存实亡 |
| `Ctrl` 按住时取消穿透 | 要低级键盘钩子，为一个提示框不值（7.6 已否决） |
| **自己问系统光标在哪** | 2 Hz 轮询 `GetCursorPos` + 矩形判定，**已采纳** |

## 2. 实现

| 文件 | 内容 |
| --- | --- |
| `Controls/FieldTooltip.cs` | 新增。代码构造的提示框窗口（无 XAML）：圆角 + 投影 + 深浅两套配色 |
| `TaskbarWindow.xaml.cs` | `StartHoverWatch` / `PollHover` / `ShowTooltip` / `HideTooltip` / `BuildTooltipText` |
| `Interop/Win32Window.cs` | `TryGetCursor`（包 `GetCursorPos`） |
| `Interop/Taskbar.cs` | `HoverOverride`（自测专用） |
| `App.xaml.cs` | `--hover-probe x,y` + `--hover-probe-clear <ms>` |

要点：

1. **文本直接取条上那份 `FloatField` 的字符串**，不重新格式化。
   否则会出现"条上写着 65%、提示里说 66%"—— 两套取值路径迟早对不上。
2. **`Bottom` 有歧义**：有时是次值（GPU 温度、内存已用/总量、上下行速率），
   有时只是把字段名再写一遍（FPS / PWR / LAT）。判据是 `Bottom == field.Key`，
   命中就跳过，否则会打出 `FPS：—   FPS`。
3. 盘型号/温度是条上放不下的信息，只能在这里补（7.6 点名要求的）。
   没有管理员权限时 NVMe 温度读不到（R8），此时行尾不追加 `—` —— 少一个符号比多一个更清楚。
4. 提示框 `WS_EX_TRANSPARENT`：它是 layered 窗口，加这个才真正让鼠标穿过去点任务栏。
   另加 `WS_EX_NOACTIVATE` 不抢焦点（A-33 说过它会让 `DragMove` 与右键菜单失灵 —— 这里两者都没有）。
5. **允许 `AllowsTransparency`**（会走软件合成）：圆角 + 投影只有 layered 画得出来，
   而这是个几十毫秒寿命的小方块，不承载毛玻璃、不参与 A-26 的常驻渲染面。
6. 定时器 500 ms，第一行就判 `!IsVisible` —— 切到悬浮窗/大窗口时提示框会自己收起，
   否则屏幕上会留一张没人认领的浮层（它是独立顶层窗口，不随条隐藏）。

## 4. 两个把验证带偏的坑

1. **`SetCursorPos` 依然不可靠**（M4.1 已记过一次，这次又踩）：设 `(68,1576)` 读回
   `(1251,895)` —— 光标被真实鼠标挪走。而"鼠标是否停在条上"正是这条功能的唯一输入。
   只能加 `--hover-probe x,y` 伪造光标位置，命中判定与显示/摆位全走生产代码。
2. **`--shot-screen` 在任务栏视图下只输出任务栏那一行**（2560×48）。
   提示框在条**上方**，根本不在图里 —— 白截两张。要按提示框自己的
   `GetWindowRect` 用 `shot-bar.py` 抓屏（`FindWindow(None, "CoPulTip")`，
   标题只为自测存在，外观上看不见）。

## 5. 开销

| 状态 | 每次 tick 的工作 |
| --- | --- |
| 条不可见（大窗口 / 悬浮窗 / 全屏切换后） | 一次 `!IsVisible` 判断即返回 |
| 条可见、光标不在条上 | `GetCursorPos` + `GetWindowRect` + 4 次比较 |
| 条可见、光标在条上 | 上述 + 拼文本（仅在内容变化时真正改 UI）+ 一次 `SetWindowPos` |

2 Hz、两个 user32 调用，量级远小于现有的 1 Hz 巡检与 2 Hz 数据刷新，
不构成 A-26 的新渲染面。

---

## 6. 已知限制

1. 提示框在屏幕上存在期间会**盖住条上方那一条**（高约 200 px）。这是 tooltip 的固有行为，
   不是遮挡 bug —— 鼠标一移开就消失。
2. 硬盘温度需要管理员权限（R8）。非提权时只显示盘型号，不显示温度。
3. 只列当前**可见**的字段。用户关掉的字段不会出现在提示里 —— 关掉就是为了不看。
