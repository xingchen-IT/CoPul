# CoPul 芯脉 0.1.0

把 CPU、GPU、内存、硬盘、网络和帧率贴在 Windows 任务栏上的轻量监控工具。首个公开版本。

![大窗口](https://gitee.com/stardust-xingchenya/corevessel-co-pul/raw/main/docs/screenshots/main.png)

## 下载

| 文件 | 说明 |
| --- | --- |
| `CoPul-0.1.0-win-x64.zip` | 绿色免安装包（约 69 MB，解压后约 166 MB） |
| `CoPul-0.1.0-win-x64.zip.sha256` | 校验和 |

**校验方法**（Git Bash / PowerShell 均可）：

```bash
sha256sum -c CoPul-0.1.0-win-x64.zip.sha256
```

Windows 上也可以：`certutil -hashfile CoPul-0.1.0-win-x64.zip SHA256`，与 `.sha256` 文件里那串比对。

## 运行

1. 解压到任意目录（**不要**只解压一部分文件，缺 `runtimes` 或 `presentmon` 会少功能）。
2. 双击 `CoPul.exe`。首次启动会要求阅读并同意许可协议，不同意则直接退出。
3. 程序**不需要安装 .NET**：包里自带运行时。
4. 想真正退出，用托盘图标的右键菜单 →「退出」。点窗口的关闭按钮只是收起。

包内 `使用说明.txt` 是同内容的离线版，可随包转发。

## 系统要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 1809 及以上 / Windows 11 |
| 架构 | x64 |
| 权限 | 普通权限即可运行；**管理员权限才能拿到全部指标**（见下） |

## 九项指标

CPU 占用（含核心网格）· CPU 温度 · 内存（含占用条）· GPU 占用 · GPU 温度 · 显存 · 硬盘占用与温度 · 网络上下行 · 帧率（FPS / 帧时间）

三种视图可同时显示：**大窗口**（明细）、**悬浮窗**（压桌面）、**任务栏条**（贴任务栏）。三者互不干涉，各有独立开关。

## 权限与降级（不是故障）

普通权限下有三项拿不到，界面显示 `—`，设置页 →「传感器诊断」会逐项写清原因：

| 指标 | 普通权限下的原因 | 解决 |
| --- | --- | --- |
| CPU 温度 | 需要读 MSR，驱动句柄被拒 | 管理员身份运行 + 自行安装 PawnIO |
| 硬盘温度 | 需要物理磁盘句柄 | 管理员身份运行 |
| 帧率 | PresentMon 的 ETW 会话被拒绝 | 管理员身份运行（或把用户加入「性能日志用户」组） |

**本程序不随包分发任何内核驱动**。CPU 温度依赖 PawnIO，但它必须由微软签名的正规渠道取得，所以只能由你自行安装（程序会检测并提示）。这是硬约束，不是省事：Windows 10 1607 起内核驱动必须微软签名，而个人开发者拿不到 EV 代码签名证书。

## 已知限制

- **安装包未做代码签名**。首次运行时 SmartScreen 可能提示「未知发布者」，需要点「更多信息 → 仍要运行」。下载后请先核对上面的校验和。
- 副屏任务栏未适配（只在主屏任务栏上显示）。
- 部分游戏独占全屏时，悬浮窗可能「看不见但点得到」——这是显卡驱动的独立翻转层旁路，属已知问题，全屏检测已在能识别的场景自动让路。
- 温度/帧率这两类指标在部分硬件上可能识别不到，属于采集库的支持范围问题。

## 数据与隐私

全部指标在本机采集、本机显示。**不联网、不上传、无遥测、无账号**。配置与日志只落在本机：

- 配置：`%APPDATA%\CoPul\config.json`
- 崩溃日志：`%LOCALAPPDATA%\CoPul`
