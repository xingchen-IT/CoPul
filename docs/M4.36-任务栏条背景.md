# M4.36 任务栏条背景：跟随 / 自定义 / 透明

> **已被 M4.37 修订**：「跟随任务栏」档（垫一层按亮度反色的对比底）已删除 ——
> 用户明确"跟随系统任务栏就是和透明一个意思"。现行只有 透明（默认）/ 自定义 两档，
> 见 `M4.37-任务栏背景两档.md`。本文保留当时三档的实现与取证记录。

## 需求

「为任务栏模式也添加自定义背景的功能，但是要额外有透明模式选项，并且将设置选项与悬浮窗外观放到一起。」

拆成三条可验收的：

1. 任务栏条**能自己给底色**（颜色 + 不透明度），不再只有"按任务栏亮度垫一层反色"这一种。
2. 额外一档**透明**：不画底、不模糊，字直接浮在任务栏上。
3. 设置页里这组控件**与「悬浮窗外观」挨着**，不要埋到「任务栏条」那张卡的下面去。

## 三档怎么画

`TaskbarWindow.ApplyBackdrop` 一个 `switch` 分三支，**只负责"底"，不管字色**
（字色仍由 `ApplyInk` 先算好再传进来 —— 两者本来是两个旋钮）。

| 档 | `Shell.Background` | DWM accent | 字色判定 |
| --- | --- | --- | --- |
| `auto` 跟随任务栏 | 浅底铺白 33% / 深底铺黑 40% | acrylic `tint 0.10` | 采样任务栏实际亮度（`Taskbar.SampleLuma`） |
| `custom` 自定义 | `#AARRGGBB`，alpha = 不透明度 | acrylic `tint 0.10` | **按自定义底色**判深浅 |
| `transparent` 透明 | `Transparent` | **`BLURBEHIND` + `tint 0`**（`blurOnly`） | 采样任务栏（没有"自己的底"可判） |

三条取舍都写在代码注释里，这里只留结论：

- **透明档不能只把 Brush 设成 Transparent。** 条是独立顶层窗口（A 方案），
  非 layered 窗口的客户区 alpha 会被 DWM 丢掉，纯"不画底"会变成一块黑。
  必须走 `ACCENT_ENABLE_BLURBEHIND` —— 它的着色基底是 0 也不做模糊，
  于是窗口区域真的透出任务栏（悬浮窗的「极透」档是同一条路）。
- **自定义档的「自动」文字色要跟着自定义底色走，不能再去采样任务栏。**
  用户把底铺成 `#F0F0F0` 而任务栏是深色，按任务栏判定就会给浅字叠浅底，整条糊掉。
- **透明档里 DWM 那圈 1 DIP 边框必须一起去掉。** 底去掉之后它就是整条上唯一还看得见的东西。
  150% 缩放下实测 2 个设备像素、亮度 90 左右（条内只有 57），看着像一个空心描边盒子。
  切回另外两档要显式还原 `DWMWA_COLOR_DEFAULT` —— DWM 会一直记着 `NONE`，不会自己回来。

## 设置页

新卡片「任务栏条背景」**紧跟在「悬浮窗外观」下面**（`SettingsWindow.xaml`），
没有并进同一张卡：上一张管的每一项都只作用于悬浮窗，混在一起用户会以为"毛玻璃浓度"也管条。

- 背景：三档分段（跟随任务栏 / 自定义 / 透明）
- 色板 8 格 + `#RRGGBB` 输入框 + 「应用」——**点色板会自动切到「自定义」档**，不用再点回去
- 不透明度：滑块 0–100，右侧同值文字
- 自定义那一块在另外两档下**置灰不隐藏**：切换档位时行高不跳，眼睛不用重新找

色板是**另一张表**（`BgPresets`），不复用 `FloatInk.Presets`：文字要的是"贴在底上最高对比"
（含纯白、深墨），底要的是"有存在感但不抢戏"（全是中低明度实色）。混用会在两边都错。

落盘时机：滑块拖动中只改窗口与内存里的 `AppConfig`（`persist:false`），
松手（`OnMouseLeftButtonUp`）才 `ConfigStore.SaveCurrent()` —— 一次拖动会产生几十个值。

## 验收

Release 编译 0 警告 0 错误。取证用独立副本 `D:\CoPulProbe`（源码目录 ACL 带 Deny），
每次进程用完即退，串行跑。

### 1. 三档的像素差异（同一行、紧邻任务栏像素作基准）

`--tray --shot-screen` + `--tray-raise`，条 rect = `(8,1528)-(688,1600)`，PNG 原点 = 任务栏左上角。
采样行 `y=36`：

| 档位 | 条内 x=12 | 紧邻条外 x=7（任务栏自身） | 判定 |
| --- | --- | --- | --- |
| 跟随任务栏 | `(31,35,43)` luma 34 | `(55,62,88)` luma 62 | 压暗 28 级 —— 叠了 40% 对比底 |
| 自定义 `#243040` / 70% | `(38,50,67)` luma 48 | 同上 | 与设定色 `#243040` 吻合（+亚克力 10%） |
| 透明 | `(56,66,81)` luma 64 | 同上 | 与任务栏差 2 级 —— 真的透出来了 |

条内 660×14 区域的主色同时印证：`auto #1D2029` / `custom #233243` / `transparent #353A4B`。

### 2. 边框

| 档位 | 条顶 `(100,1)` | 条左 `(8,36)` | 条内 `(100,36)` |
| --- | --- | --- | --- |
| 跟随任务栏 | 96 | 87 | 36 |
| 自定义 | 100 | 88 | 48 |
| 透明（改后） | **70** | **63** | 70 |

透明档边缘与内部亮度拉平 = 边框确实没画；另两档保持原样（不属于本次改动范围）。

### 3. 设置页 → 窗口 → 配置 三段一致

`--settings-probe "bgmode:custom,bgcolor:#243040,bgopacity:70,bg"` 的打印：

```
taskbarbg: mode=custom color=#243040 opacity=70 customEnabled=True hex='#243040'
           seg=[auto=False,custom=True,transparent=False]
bgswatch: [#243040] checked=True   （其余 7 格 False）
taskbarbg: window=backdrop=custom color=#243040 opacity=70 shell=#B2243040 glass=Accent Acrylic
```

`#B2` = 178/255 = 70%，`243040` = 设定色 —— 控件、窗口画刷、配置三处对得上。
透明档同法验一次：`customEnabled=False`（自定义块整块置灰）、`shell=#00FFFFFF`（alpha 0）、
`glass=Accent Blur（极透：不模糊、不着色）`。

### 4. 落盘

用窗口那一路改完后 `config.json` 里读到 `TaskbarBackdrop=transparent`、
`TaskbarBackdropColor=#243040`、`TaskbarBackdropOpacity=70`；取证结束已还原。

## 遗留

- 托盘右键菜单里还没有这组的入口（只做了设置页）。用户没要，先不加。
- 两档之间的切换会重算一次 `Taskbar.SampleLuma`（拖动滑块时每帧一次）。量级是一次 4×4 采样，
  与原有的 `ApplyInk` 同频，没有新增常驻开销。
- 透明档下如果壁纸很花，字可能不好认 —— 提示文案里写了"这时可以调「文字取色」"，没有自动兜底。
