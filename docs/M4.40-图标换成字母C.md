# M4.40 图标换成「字母 C · 脉冲环」

> 需求：「@截图 我说的是用这个图标」——用户指的是第一轮 16 个候选里的 **3 号 字母 C · 脉冲环**，
> 不是 M4.39 落地的推力喷管。
>
> 归因：上一轮的选项文案是「选 3 增加细节」，歧义在于"3"既可读作"第 3 个候选"，
> 也可读作"第 3 项操作"。**以后选项里不要出现可被当成序号的单字**——写成「① 字母 C」或
> 「字母 C（第一轮第 3 个）」这种同时给出名称和位置的表述。

## 1. 量参考图，不凭印象画

用户给的截图是 169×168 的真实渲染，先用脚本把几何量出来，再按比例写生成器：

| 量 | 参考图（89px 底盘） | 归一化 |
|---|---|---|
| 环外径 | 26px | 0.300 |
| 环内径 | 14px | 0.165 |
| 环厚 / 外径 | 12 / 26 | 45% |
| 缺口张角 | 约 66°（-64° ~ +2°） | 见下 |
| 琥珀块 | 11 × 9 px | 径向 0.202~0.300、角度 -20°~-2° |
| 中心白点 | r = 4.8px | 0.058 |
| 底盘圆角 | ≈ 20px | 0.225 |

两条从量测里才看得出来、凭印象一定会画错的特征：

1. **环厚是外径的 45%**，不是常见的 15~20%。细环在 16px 下会断成几个点。
2. **缺口两端朝缺口方向外张**：外缘比内缘多转约 8~10°。若按径向切，端面是两条指向圆心
   的直线，看起来像"被切掉一段的甜甜圈"；外张之后才有字母 C 的收笔。

## 2. 三个必须改的地方

### 2.1 琥珀块不能用扇形

第一版用角度插值画扇形，渲出来像一只"倒料的嘴"，且正好和环的下端连成一个 **G**。
改成直边四边形（`amb_points()` 取四个角、`add_poly` 填充）后，它才读作"一块独立的读数条"。

### 2.2 高光的插值方向写反了

写 `(ap1 - ap2) * 0.16 + ap2` 得到的是"从内缘向外的 16%"，高光于是盖住整块琥珀的 84%，
只剩左缘一条本色。逐像素采样才发现（条内是 `#F7CB88`、左缘才是 `#E2A64C`）。
正确写法是 `ap1 + 0.16 * (ap2 - ap1)`。**这类错误看缩略图看不出来，只能采样。**

### 2.3 16px 下琥珀必然和环粘连

缺口 13° 在 16px 上只有 0.9 个像素的缝 —— 无论怎么调都粘。小尺寸换策略：
环加大加厚（外径 0.342、内径 0.176），琥珀**向外探出环轮廓**（径向到 0.352）。
即使粘连，轮廓上也还剩"环 + 一个凸起"两个形状，不会被读成 G。

## 3. 托盘两版

| 版 | 画法 | 理由 |
|---|---|---|
| `copul-tray-light.ico`（浅色任务栏） | 深底盘 + 青环 | 同主图标，靠暗底盘压出轮廓 |
| `copul-tray-dark.ico`（深色任务栏） | **无底盘**，裸环 + 白点 + 琥珀 | 深底 + 深盘 = 整块溶解（M4.39 试过反相亮盘，读成一个白斑）。裸环在深底上最清楚 |

深色版把环放大到 0.430，并提亮一档（`#4FD2E4`）。选版仍由 `ResolveTrayIcon()` 按
`Taskbar.SampleLuma` 判定，未变。

## 6. 遗留

- Windows 有图标缓存：换 exe 后资源管理器/任务栏可能还显示旧图标，注销一次或清
  `%LocalAppData%\IconCache.db` 即可。
- 托盘图标只在启动时选一次（`ResolveTrayIcon`），改任务栏亮度不会热切换——与既有行为一致。
