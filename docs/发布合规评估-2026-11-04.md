# 发布合规评估（2026-11-04）

> 问题：「按以上顺序（关于页 → 发布脚本 + 安装包）发布是否合法」
>
> 结论先说：**顺序本身不涉及合法性** —— 先做关于页还是先做安装包，法律上没有先后要求。
> 合法性取决于五个实体条件，其中**一个当前不满足**（用户同意环节），两个刚补上（开源组件义务）。

---

## 一、逐项核对

| 事项 | 依据 | 评估时现状 | 判定 |
| --- | --- | --- | --- |
| 专有许可能否禁止二次分发 | 《计算机软件保护条例》第八条（复制权、发行权、信息网络传播权）、**第十八条「许可使用合同中未明确许可的权利，被许可人不得行使」**、第二十四条（未经许可发行或网络传播：民事责任，并可处每件 100 元或货值 1–5 倍罚款） | LICENSE 已写明禁止二次分发 | ✅ **有法律抓手**，不是一句空话 |

## 二、唯一必须补的功能：用户同意环节

**为什么必须做**：中国法院认可点击合同，但要求「条款可获取 + 同意有记录」。目前用户从任何渠道拿到 exe，双击就能用，**没有任何同意动作**。一旦发生纠纷，对方可以主张合同未成立 —— 那么「禁止二次分发」与「免责声明」这两段最关键的条款都用不上。

**怎么做**（二选一，建议两个都做）：

1. **首次启动时**弹一个协议窗口：中文全文可滚动、底部「我已阅读并同意」+「不同意则退出」，同意结果写入配置（记录版本号与时间）。
2. **安装包里**同一段文字 + 勾选框，未勾选时「下一步」置灰。

注意：不能只做「继续使用即视为同意」的隐式提示，那是最弱的一种，举证时几乎不起作用。

## 三、分发渠道的选择（决定要不要备案）

| 方案 | 备案义务 | 说明 |
| --- | --- | --- |
| **Gitee Release**（推荐） | 无 | 平台本身已备案，你只是平台用户。上传安装包 + SHA-256 校验和即可 |
| 自建下载页（国内服务器） | **必须 ICP 备案**（非经营性，免费，约 20 个工作日） | 未备案：责令改正 + 罚 1 万元，拒不改正关闭网站 |
| 网盘分享链接 | 无 | 但链接易被转手，且无法证明是官方渠道 —— 与「禁止二次分发」的初衷冲突 |

**建议**：先 Gitee Release。它的副作用是「公开仓库 + Release 下载」在平台上属于正常使用，不产生备案义务。

## 四、内核驱动这条路的事实

PawnIO 不随包分发不是「省事」，而是**个人开发者的硬约束**：

- Windows 10 1607 起，内核驱动必须由**微软**签名（不是「有 CA 证书就行」，自签名与第三方 CA 签名默认都加载不了）。
- 微软签名有两条路：WHQL（跑完整 HLK 测试）与 attestation（不跑测试，但仍需 **EV 代码签名证书**）。
- EV 代码签名证书要求**企业/组织资质审核**（工商信息、物理地址、电话核实），个人开发者基本申请不到；费用每年数千元。

所以：**永远不要把 PawnIO（或任何驱动）打进安装包**。当前做法（检测缺失 → 提示用户去官网装）是唯一合法且可持续的路径。

## 五、红线清单（写进开发守则）

1. **不做任何游戏相关功能**：不读游戏内存、不拦截或修改网络包、不模拟键鼠输入、不绕过或探测反作弊。一旦沾上，「专门用于侵入、非法控制计算机信息系统」的认定风险就出现了 —— 已有内核级外挂被判 285 条第三款的实际判例。
2. **不随包分发任何内核驱动**，不静默安装驱动，不代用户点「信任并安装」。
3. **不收钱**（在没有经营主体之前）。收费会同时带来：需要营业执照与税务登记、消费者权益保护义务、以及更高的产品质量责任预期。
4. **不隐藏身份**：exe 属性、关于页、LICENSE 里的作者信息保持一致，便于维权时证明同一性。

## 六、顺带修掉的两处开源合规瑕疵

评估过程中发现 LICENSE 有两处不完整，已一并补上：

| 问题 | 修法 |
| --- | --- |
| MPL-2.0 §3.2 要求告知源码获取方式，原文只写「遵循其原始许可」 | LICENSE 第三节补 LHM 源码仓库地址 + MPL-2.0 全文地址；新增 `THIRD-PARTY-NOTICES.txt`，csproj 复制到输出目录 |
| 自包含发布随包了 .NET 8 运行时（MIT），清单里没有 | 同上，列入第三方清单并注明「仅自包含发布版随包」 |

`THIRD-PARTY-NOTICES.txt` 同时是「关于页」的数据源：版本、许可、源码地址、分发形态都在里面，关于页直接读它即可，不用另写一份。

## 七、登记与维权（可选）

- **著作权登记**：不登记也享有著作权（条例第五条），但登记证是诉讼中的初步证据，且部分平台上架/维权投诉会要求提供。个人登记费用低、可线上办理，建议发布后再补。
- **发现盗版怎么办**：① 向托管平台/网盘发侵权通知（平台有删除义务）；② 向当地版权局投诉（行政查处比诉讼快、成本低）；③ 诉讼（法定赔偿上限 50 万元/件）。
