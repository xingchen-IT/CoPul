## 注意：规格书停在 M4.0

最新一版 `v0.18` 只写到 **M4.0（2026-10-29）**。此后到 0.1.0（M4.46）之间的实现没有再回写进规格书。

所以判断「程序实际是什么行为」时，看这几处而不是这里：

- 行为与界面：`README.md`、`docs/RELEASE-v0.1.1.md`
- 每一轮的实现与取舍：`docs/M4.*-*.md`
- 权威实现：`src/`

## 为什么留着而不删

第 15 章的 24 项决策（`Q-01` ~ `Q-25`）与假设（`A-01` ~ `A-41`）在后续的每份里程碑报告里被反复引用。
删掉快照，那些「按 Q-25 转接受现状」之类的结论就没有出处了。

早期版本（v0.2 ~ v0.12）未入库，只存在于开发过程记录中。
