# M4.26 三个视图可以同时显示

需求原话：

> 将行为改为这三个模式能够同时显示

三个模式指托盘菜单里那三项：**大窗口 / 悬浮窗 / 任务栏条**。8.1 与 A-06 从第一版起就规定
"任意时刻只有一个视图可见"——切到 A 就把 B、C 藏掉。这一版把这条**互斥**作废，改成三者各自
独立开关，可以任意叠加。编译：0 警告 0 错误（Release）。

叠加之后有三处旧假设会失效，逐条与用户确认后定：

| 问题 | 用户选择 |
|---|---|
| 进全屏怎么办 | **只收起任务栏条**，悬浮窗与大窗口照常显示；退出全屏再把条放回来（本来没收过就不放） |
| 托盘左键 | **全部隐藏 ↔ 恢复上次的组合**（一键清屏 / 一键收回） |
| 关大窗口 | **只关它**，其它视图还在就继续跑；退出统一走托盘「退出」 |

---

## 1. 行为对照

| 场景 | M4.25 及以前 | M4.26 |
|---|---|---|
| 点托盘「悬浮窗」 | 大窗口/条被藏掉 | 悬浮窗叠加上去，其它不动 |
| 三视图 | 永远只有 1 个可见 | 可同时 3 个（实测同屏 rect 互不重叠干预） |
| 托盘左键 | 切换"当前模式"那个窗口 | 全部隐藏 ↔ 恢复上次组合 |
| 全局热键 | 大窗口 → 悬浮窗 → 条 循环 | 与托盘左键同一套（全部隐藏 / 恢复） |
| 进全屏 | 条 → 浮窗（互斥切） | 收条 + 弹浮窗，大窗口保留 |
| 退全屏 | 浮窗(auto) → 条 | 收 auto 浮窗 + 放回条；**manual 浮窗保留** |
| 关大窗口 | 退出整个程序 | 还有别的视图 → 只收起；都没有 → 照旧退出 |
| 托盘提示 | 当前模式名 | `大窗口+悬浮窗+任务栏条` / `已隐藏` |

## 3. 关键设计

### 3.1 真相位只在一个地方

`shownXxx` 是唯一真相，`CurrentView` 降级成"最近操作过谁"（只给日志和探针看）。
状态机要判"条开没开"，走注入的 `IsShown` 回调（`FullScreenAutoSwitch.IsShown`），
没注入时退回旧行为 `CurrentView == v`——这样 `--fullscreen-probe --fs-fake` 那类
不建窗口的探针不用改造就能继续跑。

### 3.2 全屏会话要记"欠账"

进入全屏时真收过条 → `_fullSession = true`；退出时按它决定要不要放回来。
**它必须参与 `NeedsPolling`**：全屏中用户把浮窗也关了，屏幕上就没有"需要检测的视图"了，
但只要欠着把条放回来，定时器就不能停——否则条永远回不来。

### 3.3 关大窗口为什么不是直接改 ShutdownMode

`App.xaml` 是 `ShutdownMode="OnMainWindowClose"`，探针与托盘退出共二十多处靠
"关窗即退出"收尾。改成 `OnExplicitShutdown` 会让这些路径全部挂住。
所以只在 `Closing` 里拦：还有别的视图 → `Cancel = true` + `Hide()`；一个都没有 → 放行（老行为）。
`Application.Shutdown()` 期间 WPF 用 `InternalClose(shutdown: true, ignoreCancel: true)`，
忽略 Cancel，所以托盘退出与探针收尾不受影响（实测 `--shot` 收尾时确实走了"只收起"分支，
但退出码仍是 0）。

## 4. 真机取证

全部在 `D:\CoPulRun` 用真实窗口跑，不模拟输入。

**① 叠加编排 `--view-probe`（8 步全 ✓）**

```
#1 全隐藏         可见=0 ✓
#2 显示 Main      可见=1 ✓
#3 叠加 Float     可见=2 ✓   main=True float=True
#4 叠加 Taskbar   可见=3 ✓   main=(1050,155)-(2330,1528) float=(24,1453)-(661,1504) tray=(8,1528)-(565,1600)
#5 收起 Float     可见=2 ✓
#6 收起 Taskbar   可见=1 ✓
#7 收起 Main      可见=0 ✓
#8 恢复大窗口      可见=1 ✓
```

**② 经典全屏链路 `--tray --fs-switch-probe`（7 步全 ✓）**：进全屏真切浮窗、退全屏真回条，
每步恰好 1 个可见，终态 `Taskbar / Manual`。

**③ 多视图全屏链路 `--fs-multi`（14 步全 ✓）**，这是本次改动的核心回归：

| 阶段 | 步骤 | 结果 |
|---|---|---|
| A 大窗口+条（浮窗未开） | 进全屏 | `main=True float=True tray=False` → 只收条 + 弹浮窗 |
| A | 退全屏 | `main=True float=False tray=True` → 收 auto 浮窗 + 放回条 |
| B 用户打开浮窗（三视图齐） | 进全屏 | `main=True float=True tray=False` → 只收条，两个浮层都不动 |
| B | 退全屏 | `main=True float=True tray=True` → **manual 浮窗保留**、条放回 |

**④ 关大窗口 `--main-close-probe`**

```
before: main=True float=True tray=True
after : alive=True main=False float=True tray=True
```

进程没有退出，只有大窗口收起——"after"这行能写出来就说明 `Cancel` 生效了。

**⑤ 一键隐藏/恢复**（`--switch-view "float@700;toggle-all@1800;toggle-all@2600"`，trace）

```
show Float  组合=main=True float=True tray=False
hide Float  组合=main=True float=False tray=False
hide Main   组合=main=False float=False tray=False     ← 第一次 toggle-all
show Main   组合=main=True float=False tray=False      ← 第二次 toggle-all
show Float  组合=main=True float=True tray=False
```

**⑥ 托盘菜单勾选**（`--tray --tray-menu-probe "view:main"`）
`show Main ← Taskbar 组合=main=True float=False tray=True` —— 条没有被藏掉。

**⑦ 回归**：`--fullscreen-probe --fs-fake` 自检表 11/11 + 链路 A–E 全通过；主窗口冒烟 0 异常。

## 5. 没做的事

- **组合不落盘**：启动仍是 `--tray` / `--float` / 默认大窗口三选一，退出时不记"上次开了哪几个"。
  想要开机就三视图齐，只能自己给快捷方式加参数。要持久化的话得新增配置字段并处理
  "用户删掉配置后的一次性迁移"，这一版没做。
- 设置页没加"显示哪几个"的开关：托盘菜单与托盘左键已经够用，加在设置页会与菜单形成两处状态源。
- 副屏任务栏仍未做（本机单屏无法验收）。
