# M4.51 状态灯判定：本机没有的硬件不该点亮「降级运行」（2026-11-05）

## 现象

用户在**另一台电脑**上反馈：「即使以管理员运行，也一直显示降级运行」。

设置页 →「传感器诊断」的截图给出了完整答案 —— 权限是给足的，缺的是硬件：

```
4/6 个采集器就绪 · 管理员权限：是
NVML          本机不支持   未找到 nvml.dll（未安装 NVIDIA 驱动）。
OS / PDH      就绪
MSR / PawnIO  本机不支持   未检测到 PawnIO 驱动，CPU 温度 / 功耗 / 频率不可用。
NVMe SMART    就绪
进程          就绪
帧率          就绪
```

两条 `Unsupported` 就足以让状态灯永远停在橙色，和有没有提权无关。

## 根因

`DashboardState.ApplyProviders` 用的是：

```csharp
.Where(p => p.Status != ProviderStatus.Ready)     // 旧
```

而 `ProviderStatus.Unsupported` 的枚举注释写的是「**本机没有该硬件（例如无 NVIDIA 显卡）。不算错误。**」
两边语义直接打架：枚举说不是错误，状态灯把它当降级。

后果不止是灯色不对 —— 橙灯本来用于「本该正常却出了问题」，一旦它对一批机器常亮，
就再也传不出信息：用户无法区分「这台机器就这样」和「我配错了」。

## 改法

把两类"没准备好"拆开：

| 状态 | 判定 | 状态灯 | 状态栏 |
| --- | --- | --- | --- |
| `Failed` | 硬件在，但读不到（没提权 / 驱动被拦 / PresentMon 起不来） | **降级运行**（橙） | `降级 xxx：原因；…` |
| `Unsupported` | 本机没有这块硬件（非 NVIDIA / 无 PawnIO / SATA 盘） | 运行中（绿） | `未启用 xxx、yyy` |
| 其余 | 全部 `Ready` | 运行中（绿） | `采集正常` |

不算静默降级：状态栏仍会写「未启用 NVML、MSR / PawnIO」，设置页诊断照样逐项标「本机不支持」
并给出修复建议（PawnIO 下载地址、NVML 需要 NVIDIA 驱动）。改的只是**灯**，不是信息。

同时给 `--stats` 加了一行 `runstate`（状态文字 + 状态栏原文），否则"哪一条被算成降级"
只能靠截图猜灯色。

## 取证

`DashboardState` 无参构造、`Palette` 在无 `Application` 时回退灰色画刷，所以可以脱离 WPF
应用直接喂假 Provider。临时控制台工程 `D:\m451harness`（不入库）跑四个场景：

```
[A] 运行中    | 未启用 NVML、MSR / PawnIO
[B] 降级运行  | 降级 MSR / PawnIO：读取 CPU 温度需要管理员权限（PawnIO 驱动句柄被拒）；NVMe SMART：读取硬盘温度需要管理员权限（物理磁盘句柄被拒）；帧率：FPS 需管理员权限（PresentMon 的 ETW 会话被拒绝访问）
[C] 降级运行  | 降级 帧率：PresentMon 未能启动 · 未启用 NVML、MSR / PawnIO
[D] 运行中    | 采集正常
```

- A = 用户那台机器的形态（两条 Unsupported、四条 Ready）→ 不再是降级。
- B = 没提权 → 仍然降级，原因逐条摊开（回归验证：`Failed` 没被一起放过）。
- C = 混合 → 灯按失败点亮，两类各自归位。
- D = 全就绪 → 与改前一致。

真机回归：本机（有 4060、装了 PawnIO，但没提权）跑 `--hidden --stats`，输出
`runstate : 降级运行 | 降级 MSR / PawnIO：…；NVMe SMART：…；帧率：…` ——
三个 Provider 在非管理员下都是 `Failed`，所以仍然降级，符合预期。

## 遗留

- **那台机器没有 NVIDIA GPU**（连 `nvml.dll` 都没有），所以 GPU 卡片会一直是 `—`。
  这不是本次能修的，属于 v1 只走 NVML 的限制；README 的系统要求已明确写「GPU 指标只支持 NVIDIA」。
- 那台机器的 CPU 温度可以救回来 —— 装上 PawnIO 并重启 CoPul 即可，不需要改代码。
- 状态灯的绿灯现在含义更宽（"没有 Failed"），若将来要区分「全部可用」与「部分功能缺硬件」，
  得加第四态，而不是把 `Unsupported` 塞回降级。
