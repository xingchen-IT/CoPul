# M4.28 界面视觉重排（大窗口 + 设置页）

> 起因：用户「现在的大窗口和设置页面看起来的效果太难看了，你能不能来优化一下」。
> 本轮只动视觉层（配色、间距、控件模板、一处数据形状），不改任何交互语义与采集逻辑。

## 0. 顺带修掉一个自己引入的回归（优先）

`App.Quit()` 变成了自递归：

```csharp
void Quit() { exiting = true; Quit(); }   // ← M4.27 的 sed 批量替换把这里也换了
```

`--settings` 一退出就是 `Stack overflow. Repeat 32063 times`（进程直接崩）。
改为 `Shutdown()`。这条是从 M4.27 的「主动退出统一走 Quit()」带进来的：
**批量 sed 改方法名时，方法自己的实现体也在替换范围内**。

## 1. 诊断：原来"难看"在哪

逐张看了改前截图（`ui-main.png` / `ui-set1.png`），问题不是配色，是**层级和节奏**：

| 现象 | 成因 |
|---|---|
| 九张卡连成一块黑板，看不出是九张卡 | 窗口底 `#0F1216` 与卡片底 `#151B21` 只差 6 个色阶，边界全靠 1px 描边撑 |
| 图表区先入眼的是横线不是曲线 | 网格线用 `BrushTrack #232B33`，在卡片上是三条能单独看见的亮线 |
| 四格指标底部参差 | 只有「占用率」带进度条，其余三格底部空一截，数值基线各在不同高度 |
| CPU 那行核心占用像乱码 | 20 个数字用空格连成一句，字号与间隔全一样 |
| 设置页整组控件像四个纯文字 | 分段按钮选中态只有一档底色（`#1E262F` vs 透明） |
| 每一行标签和控件横跨整张卡 | 行内用「label 靠左 / 控件贴右」，视线要横跨 500px |
| 左侧导航像没做完的骨架 | 版本号紧跟两个导航项，下面拖 400px 空板 |

## 2. 改了什么

### 2.1 调色板：建立三档层次（`Themes/Palette.xaml`）

| 键 | 改前 | 改后 | 用途 |
|---|---|---|---|
| `BrushBg` | `#0F1216` | `#0B0E13` | 窗口底，压深 |
| `BrushPanel` | `#151B21` | `#161D26` | 卡片底，提亮（差值 6 → 13 色阶） |
| `BrushStroke` | `#242C35` | `#232C36` | 卡片描边 |
| `BrushDivider` | — | `#1C242D` | **新增**：头部收边线 |
| `BrushGrid` | — | `#1A222A` | **新增**：图表网格 |

### 2.2 卡片与指标格（`Themes/Styles.xaml` / `Controls/MetricTile.xaml`）

- `BlockCard`：圆角 8→10、内边距 `16,12,16,14`→`16,13,16,15`、卡片间距 8→12。
- `TextBlockTitle` / `SectionTitle` 13→14：卡片名与正文拉开了半个档位。
- `TextTileValue` 24→25，`MiniBar` 4→3px、圆角 2→1.5（条回到"数值的注脚"位置）。
- **`MetricTile` 根布局 StackPanel → 固定行栅格**：第三行常驻 11px 进度条槽，
  没有条的格子也占位 —— 四格底边一行齐。

### 2.3 核心占用：字符串 → 网格（`Sdk/DashboardState.cs` + `MainWindow.xaml`）

- 删 `CoresText`，新增 `CoreCell`（`Text` / `Bar` / `BarBrush`）与 `ObservableCollection<CoreCell> CoreCells`。
- `SyncCoreCells()`：**只有核心数变了才动集合**，数量不变时只改格子内三个属性。
- 每格 32 宽：11px 等宽数字 + 2px 占用条，条走阈值色（>70% 黄、>90% 红）。
- 上方补一行「各核心占用率 %」——否则突然冒出一排彩条没有来由。
- 读不到时整排不画（不是画 20 个 `—`）。

### 2.4 设置页（`SettingsWindow.xaml`）

- **行栅格统一**：13 行全部改成「108px 标签列 + 内容列」，控件左对齐，
  不再出现「标签在左、开关贴右」的 500px 跨度。
- `Segment` 选中态：底色 + 1px 描边 + SemiBold，内边距 `14,6`→`12,5`。
- `Switch` 加 `Margin="-4,0,0,0"`：抵消模板里 4px 透明热区，左对齐后不会比同列控件右移 4px。
- 左侧导航 168→184，版本号 `DockPanel.Dock="Bottom"`，选中项加整块淡底
  （强调条 `Bar` 移到 `Bd` **之后**——先画会被选中态底色整根盖掉）。
- 诊断页卡片圆角与间距跟随 8→10；预览块硬编码的 `#0F1216` 改绑 `BrushBg`。

### 2.5 其它

- 大窗口/设置页标题栏下沿各加一条 `BrushDivider` 线。
- 标题栏品牌缩进 16→12，与卡片左边缘同一条线。
- 底部降级原因 12→11px：它要能读，但不该先入眼。
- 三张趋势图高度 104→92。

## 3. 取证

| 项 | 结果 |
|---|---|
| 编译 | 0 警告 0 错误 |
| `--view-probe` | 8/8 步全过（0→1→2→3→2→1→0→1），三视图互不干扰 |
| `--settings-probe` | `fields: count=9`、`interval live=2000`、熄灭 fg=`#FF6B7480`（删除线态仍在） |
| 26s 单大窗口 | `single-core 1.983%`，`ApplySnapshot 0.555 ms`，`Layout 4.550 ms` |
| 截图 | `ui-main.png`（改前）→ `ui-v2-main.png`（改后）；`ui-set1.png` → `ui-v2-set.png` |

`ApplySnapshot` 从 0.444 → 0.555 ms，是 20 个 CoreCell 的属性通知换来的；
`Layout` 从原来的"一次字符串重排"变成"20 个小 TextBlock"，26 秒共 56 帧 ≈ 1% 单核。
换来的是核心占用从"一坨数字"变成能读出瓶颈的网格，这笔账划算。

## 4. 新踩的坑

- **`--settings-probe` 配合 `--shot` 不会还原配置**。探针把 `FloatScale` 改成 125、
  `FloatVertical` 改成 true、`SampleIntervalMs` 改成 2000，全部落盘。
  取证后必须手工核对 `%APPDATA%\CoPul\config.json`。（已还原为 100 / false / 500。）
- **设置页探针串用逗号分隔多个命令，单命令的多值才用分号**。写成 `a;b;c` 会被当成一条命令，
  静默什么都不做（第一版就这么白跑了一次）。
- `ControlTemplate` 里后写的元素盖在先写的上面。给 `Bd` 加了选中底色之后，
  先画的 3px 强调条会被整根盖掉 —— 强调条必须写在 `Bd` 之后。
